    Build on my PC
    
    
    Run the builds on your own computer, with your own compiler. Nothing to install: it is one small program.
    
    
    This computer is not running Windows. Modern Visual Studio builds need Windows. Visual C++ 6 builds in a container (under Wine), and the MinGW-w64 compilers build in a container too: install Docker or Podman. You can also choose switches here and copy the cmake command.
    
    
      
      
    1. Download the agent for your computer:
        
        
          
      • Windows 64-bit or 32-bit
        • 
          
      • macOS, Apple silicon (M1 and newer)
        • 
          
      • Linux x86-64 or Linux ARM64
        • 
        
      
        On macOS and Linux, open a terminal in the download folder and run chmod +x build-agent-* first. On macOS, if it is blocked as from an unidentified developer, run xattr -d com.apple.quarantine build-agent-macos-arm64 once (or allow it in System Settings, Privacy and Security).
      2. 
      
    2. Run the agent. It downloads the game source from GitHub itself, so it needs nothing but itself (and git on this PC: it checks, and tells you how to get it if it is missing; on Windows, winget install Git.Git). It then checks this PC and tells you exactly what is missing and how to fix it. Visual C++ 6 and Visual Studio builds run from the prompt where that compiler is set up (or pass --env-script); the MinGW-w64 build needs only Docker, Podman or WSL.
      3. 
      
    3. It opens this page already connected. Pick a configuration above and press Build on my PC. The first build of a project downloads it from GitHub (a few hundred MB); later builds only fetch what changed.
